# Symmetrum

Symmetrum builds **Parity5**, a governance and evidence layer between enterprise applications and AI providers.

## What we build

- Provider-neutral AI exchange contracts
- Evidence capture at application/provider trust boundaries
- Deployment and operations tooling for regulated AI workflows
- Release, dependency, and environment automation
